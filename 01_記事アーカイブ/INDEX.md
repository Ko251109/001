## 2. ファイル名の規則（検索のしかた）

```
YYYY-MM-DD_カテゴリの話(アーティスト 日付 会場).md
例) 2026-03-01_ライブの話(TOMOO 2_27 東京国際フォーラムホールA).md
```

- **アーティストで探す** → ファイル名を Glob/Grep。例: `ライブレポート/` を `GRAPEVINE` で検索。
- **会場・演出・曲名で探す** → 本文を `grep`。過去にその要素をどう描写したか確認できる。
- **時系列で探す** → 先頭の日付でソート（ファイル名昇順 = 古い順）。

## 4. 推奨手本（最新・最も洗練された文体）

文体を合わせたいときは、まずこの3本のいずれかを読む:

- `ライブレポート/2026-03-01_ライブの話(TOMOO 2_27 東京国際フォーラムホールA).md`
- `ライブレポート/2025-12-22_ライブの話(Aooo 12_6 東京ガーデンシアター).md`
- `ライブレポート/2025-11-08_ライブの話(OASIS 10_26 東京ドーム).md`

ジャンル別の手本:

- フェス → `フェスレポート/` の近年（例: `2025-12-31_…COUNTDOWN JAPAN…`、`2025-06-07_…NANO-MUGEN FES…`）
- 年間ベスト → `音楽の話/` の「〜の10枚」（例: `2022-12-29_音楽の話(2022年の10枚).md`）
