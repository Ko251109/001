# トピックまとめテンプレート（気付きメモ → 1トピック深掘り）

> `inbox/` の気付きメモを材料に、**1つのトピックを深掘りする**ブログ記事の骨組み。
> 文体は **yaque文体で統一**する（`CLAUDE.md` のトーン規則を踏襲）。
> ただしライブレポート固有の書き出し「〇〇のライブに行ってきました。」は使わない（別ジャンルのため）。

---

## 適用する文体ルール（CLAUDE.md から）

- **文末**: 「〜ました／でした／ます／です」。感想は「〜と思います」「〜と感じました」「〜という印象があります」。
- **一人称**: 主語（私は・僕は）を省略する。
- **感情表現**: 直接語らず描写で。感嘆符・「ヤバい」「神」「最高すぎる」は使わない。
- **締め**: あっさり短く。無理に教訓化・一般化して締めない（「〜だと改めて感じました」の連発を避ける）。

ライブ描写の語彙（演奏・客席など）は**この種別では使わない**。題材に即した言葉を選ぶ。

---

## 構成テンプレート

```markdown
[書き出し：静かな入口 1〜2文]
最近、〇〇について考えることが増えました。きっかけは〜。
（または）〇〇という出来事があり、しばらく頭に残っていました。

[背景・きっかけ：メモの文脈を1段落]
〜という場面で気付いたことです。

[本論：観察 → 気付きの展開 2〜4段落]
〜でした。そこで気付いたのは〜ということです。
（事実の描写を先に置き、そこから考えたことを続ける。断定しすぎない）

[反証・揺らぎ：あれば1段落]
ただ、〜という見方もできます。

[締め：あっさり 1〜2文]
〜なのかも知れません。（言い切らず余韻で止める）
```

## チェックリスト

- [ ] 1記事＝1トピックに絞れているか（複数テーマを詰め込んでいないか）
- [ ] 主語（私は・僕は）を省略しているか
- [ ] 感嘆符・「ヤバい」「神」を使っていないか
- [ ] 気付きを断定で押し付けず、描写と推量で書いているか
- [ ] 締めはあっさり短いか（教訓の説教調になっていないか）
- [ ] 元メモの事実を捏造で膨らませていないか（足りなければ筆者に確認）
