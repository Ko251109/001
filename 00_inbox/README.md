# 00_inbox — 日々の気付きメモ

> Obsidianの `00_inbox` に対応するフォルダ。日々の気付きメモをここに置く（同期する）。
> `/inbox-draft` スキルがこのフォルダを期間で絞って読み、トピックを選んでブログ下書きにする。
>
> ※リモートのClaude Codeが読めるのはこのリポジトリ内のファイルだけ。
> ローカルObsidianの `00_inbox` のメモは、コミット＆プッシュして初めてここから参照できる。

## メモのフォーマット（推奨）

ファイル名に日付を入れると、期間の絞り込みが確実になる。

```
YYYY-MM-DD_短いタイトル.md     例) 2026-06-25_締め切りと集中.md
YYYY-MM-DD.md                  （デイリーノート形式でも可）
```

frontmatter に日付・タグを入れてもよい（任意）:

```markdown
---
date: 2026-06-25
tags: [仕事, 集中]
---
本文（気付きを自由に。箇条書きでも文章でも可）
```

## 期間の判定順（スキルの挙動）

1. ファイル名先頭の `YYYY-MM-DD`
2. 無ければ frontmatter の `date:`
3. それも無ければファイルの更新日時（mtime）

## 注意

- メモは断片でよい。スキルは**メモに書かれた事実だけ**を使い、足りない部分は捏造せず筆者に確認する。
- このフォルダはソース置き場。生成された記事は `01_記事アーカイブ/` 側に保存される。
