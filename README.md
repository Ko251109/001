## このVaultについて

このVaultは [野球(yaque)のblog](https://blog.livedoor.jp/ongaq89-yaque/) の全記事209本を解析して作成されました。
AIエージェントがこのVaultを参照することで、筆者の文体・語彙・構成パターンを忠実に再現したブログ記事を自動生成できます。

## エージェントの使い方

### 方法1：Claude Code 等のコーディングエージェント（推奨）
1. このリポジトリをエージェントに渡す
2. エージェントは `WIKI.md`（索引）→ 必要なファイルだけを自動で読み込む
3. ライブ情報（アーティスト名、会場、日付、セットリスト等）を入力
4. AIが文体を再現した記事を生成

### 方法2：Obsidian + AIプラグイン
1. このVaultをObsidianで開く
2. `CLAUDE.md` の内容をAIプラグインのシステムプロンプトに設定
3. 記事を書きたいライブ情報を入力
4. AIが文体を再現した記事を生成

### 方法3：RAG（Retrieval-Augmented Generation）
1. 全記事をベクトルDBに登録
2. 類似記事を検索してコンテキストに追加
3. `CLAUDE.md` のシステムプロンプトと組み合わせて生成
